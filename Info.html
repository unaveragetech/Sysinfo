What it scans

Comprehensive System Analysis

Collects detailed information directly in your browser — no server required.

🌐
Browser & Platform
User agent, language, plugins, rendering capabilities, WebGL, canvas, CSS features, and browser preferences.
💻
Hardware Details
CPU core count, device memory, GPU vendor & renderer, touch points, screen orientation, and color gamut.
📍
Location & IP
Cross-validated IP geolocation from three independent providers — ipapi.co, ipinfo.io, and ipwhois.is.
📡
Network Info
Connection type, downlink speed, round-trip time, HTTP/2 & QUIC support, and latency measurements.
🔒
Security & Permissions
HTTPS / secure context status, cross-origin isolation, permission states for camera, mic, geolocation, and more.
🎵
Media Capabilities
Audio context info, codec support for audio and video formats, MediaRecorder availability, and recording capabilities.
💾
Storage & Battery
Storage quota and usage with a live progress bar, plus battery level, charging status, and time estimates.
⚡
System Capabilities
WebAssembly, SharedArrayBuffer, BigInt, Bluetooth API, USB API, Serial API, and WebGL extension count.
Process

How It Works

Seven steps from page load to fully detailed report, all within your browser.

1
📥
Page Loads
Browser requests the single-page application — no backend needed.
2
🧩
Browser APIs
Navigator, Screen, WebGL, AudioContext, and other APIs are queried for local data.
3
🌍
IP Verification
Five CORS-friendly sources confirm your public IP address independently.
4
📍
Geolocation
Three geo providers cross-validate city, region, country, ISP, and coordinates.
5
🔬
Deep Analysis
Hardware specs, codec support, permissions, and security context are all compiled.
6
🖥️
Live Display
Results render in an interactive, collapsible-sidebar dashboard with copy support.
7
🔗
API Sharing
Share a link — anyone who opens it sees their own formatted system report.
